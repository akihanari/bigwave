# BigWave 🌊‼️

絵文字で書く、テンションが高いほど効率がいいプログラミング言語。
🌊に‼️を盛るほど波がデカくなる。

**▶ サイト：** https://akihanari.github.io/bigwave/

```
🌞Hello World!🌞
```

## しくみ

横一列に並んだ箱（30000個、最初はすべて0）と、今いる箱を指すサーファー🏄で動きます。
命令にならない文字はすべて飾りなので、好きなだけ盛って書けます。

## 命令

| 絵文字 | 意味 |
|---|---|
| 🏄 | 次の箱へ進む |
| 🏊 | 前の箱へ戻る |
| 🌊 | 今の箱の数を＋1 |
| 🐚 | 今の箱の数を−1 |
| 💥 | 今の箱の数を文字にして出力 |
| 🐠 | 今の箱の数を数字のまま出力 |
| 🌞…🌞 | はさんだ文字をそのまま出力 |
| 🌴 | 箱が0なら、対になる🍧の先へ飛ぶ |
| 🍧 | 箱が0でなければ、対になる🌴へ戻る |
| 🌺 | 箱が0なら、ここから先を1回だけ実行 |
| 🌈 | 箱が0でなかったときは、ここから先を実行（省略可） |
| 🐬 | 🌺〜🌈〜🐬 のおわり |

## テンション記号

直前の命令の実行回数を、左から順に変えます。

| 記号 | 意味 |
|---|---|
| ↑ | 回数を＋1 |
| ↓ | 回数を−1 |
| ‼️ | 回数を×2 |

`🌊‼️‼️‼️↓` は 1→2→4→8→7 で、🌊を7回実行します。
回数が0以下になった命令はスベって何も起きません。🌴🍧🌺🌈🐬には効きません。

## サンプル

[`examples/`](examples/) にあります。拡張子は `.bw` です。

- `hello.bw` … テンション記号だけで書いた Hello World!
- `hello_sun.bw` … 🌞で書いた Hello World!
- `multiply.bw` … ループで 3×4 を計算
- `count.bw` … 1から15まで数える
- `fizzbuzz.bw` … FizzBuzz（1〜100）
- `fizzbuzz_classic.bw` … 🌞を使わず、数字から文字を作る FizzBuzz
